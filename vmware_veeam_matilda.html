El Universo VMware — el stack completo
by Broadcom desde 2023

VMware es el estándar de facto de la virtualización enterprise desde 2001. Su stack cubre desde la capa de hypervisor hasta redes definidas por software, almacenamiento, escritorios virtuales, contenedores y migración cloud. El 70% del fortune 500 corre VMware en producción. La adquisición por Broadcom en noviembre de 2023 por USD 69 billones cambió radicalmente el modelo de licenciamiento.

🖥
VMware vSphere
ESXi + vCenter Server
Core · Hypervisor
El corazón del datacenter VMware. ESXi es el hypervisor bare-metal que corre directamente sobre el hardware físico y permite crear múltiples VMs. vCenter Server es la consola de gestión centralizada que orquesta múltiples hosts ESXi en un cluster.

Con vSphere se obtiene: alta disponibilidad (HA), vMotion (migración en vivo de VMs sin downtime), DRS (balanceo automático de carga entre hosts) y FT (Fault Tolerance para VMs críticas).
vMotion (live migration) HA / DRS Storage vMotion Fault Tolerance
💾
VMware vSAN
Virtual SAN — Software Defined Storage
Storage · HCI
Almacenamiento definido por software que agrega los discos locales de cada host ESXi en un pool compartido de storage distribuido. Elimina la necesidad de una SAN física externa. Forma la base de la infraestructura hiperconvergente (HCI) de VMware.

vSAN ofrece políticas de almacenamiento por VM, deduplicación, compresión, cifrado nativo y stretched cluster para DR entre dos sites.
HCI Dedup & Compression Stretched Cluster Encryption nativo
🌐
VMware NSX
Network & Security Virtualization
SDN · Micro-segmentación
Red definida por software que abstrae el hardware de red (switches, routers, firewalls) en capas virtuales gestionadas centralmente. NSX crea redes overlay sobre la red física existente, permitiendo micro-segmentación (firewalls a nivel de cada VM) y automatización de políticas de red.

NSX-T (versión actual) soporta ambientes multi-cloud y es la base del networking de VMware Cloud.
Micro-segmentación SDN Overlay Distributed Firewall Load Balancer
☁️
VMware Cloud Foundation (VCF)
vSphere + vSAN + NSX + Aria — todo en uno
Nuevo SKU Broadcom
La nueva forma de licenciar VMware post-Broadcom. Broadcom eliminó la venta de productos individuales (vSphere, vSAN, NSX por separado) y los empaquetó en VCF. Ahora hay que comprar el bundle completo aunque solo se use el hypervisor.

VCF incluye: vSphere, vSAN, NSX, Aria (ex-vRealize), y Tanzu Standard. El precio cambió de perpetual por socket a suscripción por core — triplicando o multiplicando el costo para muchas organizaciones.
Bundle forzado Suscripción por core Sin perpetual
🚀
VMware HCX
Hybrid Cloud Extension
Migración · L2 Extension
La herramienta de migración nativa de VMware. HCX extiende la red del datacenter on-premise hasta el cloud (AWS VMware, Azure VMware, Personal Tech) y permite migrar VMs con vMotion cross-cloud — sin cambiar IP, sin reconfigurar aplicaciones, con cero downtime.

HCX también hace replicación continua (bulk migration) para mover grandes volúmenes de VMs en paralelo.
vMotion cross-cloud L2 Network Extension Bulk migration Zero downtime
🐳
VMware Tanzu
Kubernetes Enterprise Platform
Containers · K8s
La apuesta de VMware al mundo de contenedores. Tanzu es la plataforma Kubernetes enterprise que corre sobre vSphere, permitiendo gestionar clusters K8s con la misma herramienta con la que se gestionan las VMs. Incluye Tanzu Application Platform (TAP) para developer experience y Tanzu Mission Control para gestión multi-cluster.
vSphere with Tanzu Tanzu App Platform Mission Control
🖥
VMware Horizon
VDI — Virtual Desktop Infrastructure
VDI · DaaS
Escritorios y aplicaciones virtuales entregados desde el datacenter. El usuario final accede a su escritorio Windows completo desde cualquier dispositivo (thin client, tablet, PC vieja) sin que nada crítico esté en el endpoint. Los datos viven en el servidor.

Horizon es especialmente relevante para sectores regulados (banca, salud) donde el dato no puede estar en el endpoint del empleado.
VDI persistent / non-persistent BLAST Protocol App publishing
🔄
VMware Site Recovery Manager (SRM)
Disaster Recovery Automation
DR · Automatización
Automatización del proceso de Disaster Recovery. SRM orquesta el failover de VMs desde el site primario al site de DR con un solo clic — o de forma totalmente automática. Incluye pruebas de DR no disruptivas (sin afectar producción) para documentar el RTO real ante auditorías.
Failover automatizado DR Test no disruptivo RPO/RTO documentado
📊
VMware Aria (ex-vRealize)
Operations · Automation · Log Insight · Cost
Observability · Ops
La suite de operaciones de VMware. Aria Operations (monitoreo y optimización), Aria Automation (provisioning self-service), Aria Log Intelligence (análisis de logs con ML) y Aria Cost (gestión de costos multi-cloud). Juntos dan visibilidad y control completo del ambiente VMware.
Monitoring & Alerting Self-service IT FinOps multi-cloud

La regla 3-2-1-1-0 de Veeam — el estándar de protección de datos
Best Practice · Industria

La evolución de la clásica regla 3-2-1 de backup. Veeam actualizó el estándar para incluir defensa contra ransomware e inmutabilidad. Esta regla es el criterio que el BCRA y las principales certificaciones (ISO 27001, SOC2) utilizan para validar una estrategia de protección de datos.

3
Copias de los datos
Mantener 3 copias de los datos: el dato original en producción + 2 copias de backup. Si una falla, quedan dos.
2
Tipos de medios distintos
Las copias deben estar en al menos 2 tipos de medios diferentes: disco local + object storage en nube, o disco + cinta. Evita que un solo tipo de falla destruya todo.
1
Copia fuera del sitio
Al menos 1 copia en una ubicación geográficamente separada. Si hay un incendio, inundación o corte en el DC primario, la copia off-site sobrevive.
1
Copia offline o inmutable
Al menos 1 copia que el ransomware no pueda cifrar ni borrar: Object Lock (WORM), cinta offline, o repositorio Veeam con Hardened Repository (Linux). Esta es la defensa anti-ransomware.
0
Cero errores en verificación
Veeam SureBackup verifica automáticamente cada backup: arranca la VM en un entorno aislado y valida que responde. 0 backups sin verificar = certeza de que son recuperables.
Pregunta de discovery que cierra el deal de backup: "¿Cuándo fue la última vez que probaron restaurar el backup completo de su sistema ERP y cuánto tardó?" El 80% de las empresas nunca lo hicieron. Con Veeam + Personal Tech, esa prueba se hace automáticamente cada noche y el resultado queda documentado para la auditoría.
